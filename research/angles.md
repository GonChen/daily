# 搜索角度轮换池

每次生成日报时从本文件取 6–8 个未用角度分配给各 scout（在各桶 prompt 里注入），用过的移到"已用"并注明日期。scout 也可以基于当日语境派生新角度，新角度用完追加回池子。目标是避免每天用同样的实体名搜索、看到同样的结果。

## 未用角度（反向问题与非实体问法）

- 长 context 的真实成本曲线本周有什么新测量？
- 谁在把投机解码推到生产，正确率代价是什么？
- 哪些"上周的故事"本周出现了反例或续集？
- 开源模型与闭源 API 的同任务成本差本周有什么新测量？
- 量化（NVFP4/MXFP4/INT8）在真实负载下的精度损失本周有什么新复现？
- prefill/decode 分离架构本周有什么新部署或新失败模式？
- 算子库之间（FA/FlashInfer/TRT-LLM kernel）同一算子的实测差距本周有什么新数据？
- 中文社区（知乎/V2EX/B站/公众号）本周在激烈争论什么与推理/芯片有关的议题？
