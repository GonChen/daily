## 1. The Inference Engineering Pareto Atlas（arXiv:2609.17863，2026-09-15）｜评测，可证伪负结果
- 类型：论文/评测（作者报告，未独立复现；已核对 abstract 页）
- 事实：Qwen2.5-7B-Instruct + vLLM 0.12、L4/A100/H100 三卡实测 54 种优化配置（36 进校准网格、18 上 Pareto 前沿），质量用 200 题 GSM8K。三条负结果：(a) 朴素 FP8 KV cache 吞吐正常但 200 题全错（0% 正确）；(b) n-gram 投机解码延迟 0.90–0.98× 基线（无收益）；(c) AWQ 4-bit 在 L4 延迟 0.34× 但 strict GSM8K 掉 5.9 个百分点、恰压在 95% 质量线下（宽松抽取与 FP16 持平，归因格式错误）。FP8 权重保留 99.4% 精度、延迟 0.61–0.65×，4 个 regime 中 3 个胜出。稀疏注意力仅模拟器评估（交叉漂移 <1.5%）。摘要页未附代码仓库链接。
- 启示：把"量化/投机解码在什么条件下不成立"做成公开锚点；FP8 KV 全错暗示直接缓存量化缺分校准即翻车。
- 来源：https://arxiv.org/abs/2609.17863
- 新事实：首个把负结果做成跨三卡 54 配置校准网格的推理工程测量。

## 2. PrefixBench-H100（arXiv:2609.19657，2026-09-17）｜基准/表征
- 类型：论文/基准（作者报告，未独立复现；"reproducible"为作者自述，摘要页无 GitHub 链接）
- 事实：单 H100、vLLM 与 TensorRT-LLM 双运行时、匹配负载，系统变化共享前缀长度、后缀多样性、到达模式、并发、输出长度与缓存配置，采集 TTFT/ITL/吞吐/缓存命中率/显存。边界结论：前缀复用的 TTFT 收益在缓存压力下被侵蚀；缓存有效性对并发和输出长度基本不敏感；剩余运行时差异来自缓存之上的调度层。
- 启示：给"前缀复用什么时候白做"划操作包络线；agent/多轮 RAG 容量规划可用。
- 来源：https://arxiv.org/abs/2609.19657
- 新事实：首个针对"prefix reuse 何时失效"的可复现单卡表征基准。

## 3. Ask the Tool, Don't Guess（arXiv:2609.18849，2026-09-16）｜论文（agent 系统 + 调度）
- 类型：论文（作者报告；来自 arXiv API 摘要，未逐页核实）
- 事实：工具调用显式上报进度信号供服务端 KV cache 管理使用，p90 TTFT 较 LRU 降约 21%；作者同时给出负结果：任何调用前估计都无法得知调用时长或可靠排序——能力边界被作者划死在"只能依赖运行中进度信号"。
- 启示：agent 负载的 KV 管理走"工具侧主动上报"而非"服务端猜测"；静态预测调用时长类方案在该框架下被证伪。
- 来源：https://arxiv.org/abs/2609.18849
- 新事实：工具调用运行时进度作为调度/KV 退役信号 + 调用前估计不可行的负结果论证。
