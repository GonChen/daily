# 2026-09-19 deep-03：国产推理的两个定价方向

问题：同一周，两家中文头部模型公司对"国产推理规模化"给出相反的定价动作，共享同一个前提主张。

| | DeepSeek | 智谱（Z.ai / bigmodel） |
|---|---|---|
| 动作 | 9-14 起 `deepseek-v4-pro` 强制路由 V4.1-Flash 按 Flash 价计费；后又宣布 V4 Pro 续供、计费不变 | 9-18 发布 GLM-5.3-FlashX：200 tok/s（5×），定价提至 2.5× |
| 价格信号 | 峰值输入 $1.32→$0.30（约 −4.4×）、输出 $3.96→$1.20（约 −3.3×）；cache hit $0.006 | Flash 现价输入 0.8 元/输出 2.7 元每百万 tokens 的 2.5 倍 |
| 规模化主张 | 552B MoE、输入 8B 激活/输出 16B，KV cache 占 HBM 1/4（架构摊薄） | 官方点名"10 万张国产芯片"推理底座 |
| 可验证性 | 端点计费规则公开可查（api-docs），任何调用方当日可复核 | "10 万张"与 E2E 3× 为主张口径；HN 403 pts 讨论中零独立复现，客户侧报告 API 慢/配额消耗快 |

开源栈的对齐证据（可复核）：V4.1-Flash 权重 9/10 已放出；本周 FlashMLA 修 CUDA 13/MSVC、DeepGEMM 修 Mega MoE、DeepEP 修 doorbell；DeepJIT 新开源——header-only JIT 编译缓存库同时以 CUDA 与昇腾 NPU 为一等公民后端。同期华为口径："CANN 全面开源、月活开发者 5200、跨越生态拐点"。

编辑判断：
1. DeepSeek 用架构（小激活 + KV 摊薄）走降价通道，把旗舰流量迁到便宜路径，本质是用推理效率换取调用规模；智谱用提速 + 稀缺性走提价通道，本质是把规模化主张转译为定价权。两条路线可以同时成立，但要求的前提不同：前者要求单位 token 成本真实下降，后者要求买方为"国产规模化"支付溢价。
2. 两条路线的可验证性差距很大：DeepSeek 的价格规则公开可查、开源栈一周四笔实质修复可复核；智谱的"10 万张/3×"目前零独立复现。把后者当基准事实引用之前，应等 CANN/昇腾社区数据或第三方 serving 复测。
3. 证伪条件：若 V4.1-Pro 上线后价格回归 Pro 档、或 FlashX 提价后调用份额数据（第三方网关统计）下滑，则对应叙事收窄。
