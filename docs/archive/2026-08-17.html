Executive readout

AI 基础设施的约束，正在从“买到 GPU”扩展为“融得到钱、送得进电、跑得稳软件”。

今晨最值得记住的不是周末多了一款芯片，而是 NVIDIA 正把 AI factory 包装成可被独立承销的基础设施资产：六家金融机构的平台目标是长期动员超过 5,000 亿美元第三方资本；与此同时，800 VDC 把下一代机架的供电密度推向 2027 年每排最高 2MW。软件侧给出同一主题的另一面：vLLM 刚为 MI355X 上 DeepSeek‑V4 sparse‑MLA 合入优化，却也因实际兼容性问题暂时让 Blackwell 的 head-dim 256 回退到 FA2。资本能扩大名义供给，工程正确性才决定有效供给。

01｜资本正在成为 AI 基础设施栈的一层

NVIDIA 的新平台不是直接宣布建成 5,000 亿美元数据中心，而是尝试把 GPU 使用率、现金流与残值变成可承销变量。若这套机制成立，竞争将从“谁有更快芯片”扩大到“谁的硬件更易转租、软件寿命更长、客户池更深、融资利率更低”。

风险也因此从供货风险扩展到信用与利用率风险。最高 25% 的残值支持说明 NVIDIA 愿意在部分项目中承担有限尾部风险，但每个项目仍由资本方独立决策。

观察链：MOU → 独立承销 → 客户 offtake → 实际利用率 → GPU-hour 价格 → 残值与再部署。只有走完前几步，名义资本才会变成有效算力。

02｜从电网到 token，供电密度与软件利用率是一张表

800 VDC 解决的是“同样空间如何安全送入更多电”；OpScale、PD 分离、KV cache、量化 MoE 解决的是“每一瓦电能产出多少满足 SLO 的 token”。只提高机架功率而不提高利用率，会把瓶颈移到变电、冷却与融资；只做 kernel 优化而电力无法交付，也无法扩张。

实践提示：容量规划统一记录 MW、机架功率、GPU 利用率、goodput、P99 TTFT、token/kWh 与 GPU-hour 毛利，而不是分成互不相干的设施表和模型表。

03｜生产推理的护城河，是“知道何时不该走最快路径”

vLLM 的 8 月 16 日主线很有代表性：一边用平台专用 Triton kernel 优化 MI355X sparse‑MLA，一边在 Blackwell 上因接口组合不受支持让 FA4 head-dim 256 回退 FA2。高性能栈不是永远选择最新 kernel，而是根据 shape、硬件、图捕获与正确性证据可靠路由。

同样逻辑也出现在 Agent：Claude Code 增加内存边界，pi 增加工具白名单，Switchyard 在模型间路由。控制面本身正在成为性能与可靠性的共同来源。

采购提示：benchmark 必须同时报告 fallback、已知问题、精度/确定性、尾延迟和版本状态；主线提交不能当成稳定发布。
