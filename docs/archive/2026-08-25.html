Executive readout

从 kernel 到 AI factory，性能结论的最小可信单位是完整、可复述的工作负载。

NVIDIA 的 AgentX 尝试把长 context、KV reuse、tool gap 和动态并发纳入机架级口径。SGLang 则展示一个 −86.6% 的滑动窗口 kernel 优化在完整 prefill 只留下 −9.4%；vLLM 展示保持 batch invariance 的 3× decode-kernel 改善也附带 +14.8 秒初始化。FlashInfer 的 warm-L2 算子收益与 DeepSeek V4 live-adapter 的数值等价，进一步说明速度、生命周期成本和语义正确性必须分门验收。

vLLM #53361 · DeepSeek V4

merge=False LoRA 的难点不是“能加载”，而是 expert weight 与非 LoRA 参数都落到正确命名空间。

深度解读

comparison · deployment consequence · falsification
深挖 01

不要把 kernel 倍数加成 AI factory 倍数。

AgentX 系统会话 → SGLang prefill → 请求 p99

系统、prefill 和 served request 是不同层级。SGLang 的 SWA kernel 725.4µs→96.9µs，但总 prefill 只从 551.6ms→499.5ms；8k/1k cc16 p99 为 −11.9%，1k/1k 却近乎中性。NVIDIA 的 AgentX 进一步包含 cache、工具等待与动态并发，因此任何跨机架的巨大倍数都必须回到同一 trace、拓扑与功耗边界验证。

层可报告数字不得外推
kernelSWA −86.6%直接变成用户吞吐
prefillGPU −9.4%覆盖 decode/队列/网络
agent factoryAgentX throughput/MW不变拓扑的采购 TCO

证伪：用同一模型、请求回放、并发、功耗和拓扑作 A/B/A；或复测 #34461/#34462 合并后的 served 指标。若优势不复现，不能用 PR 或厂商局部数字做容量计划。
