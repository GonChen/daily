推理框架与数据面

the trigger position is saturation
vLLM #57355 · 已合入

满载服务器恰好运行在 max_num_seqs 并发上，于是悬崖成为常态。

默认 CUDA graph 按 8 的倍数捕获 batch 尺寸；max_num_seqs 非 8 倍数时，最后一段 batch（如 100 时的 97–100）落入 PIECEWISE 慢路径。作者的 TP4 B200、Mistral-Small-4-119B-2603、8k–127k 混合 prompt 实验显示：过载时吞吐随运行从 2,922 衰减到 829 tok/s；Nsight 归因 PIECEWISE 下 graph-launch 间隙从 0.69 ms 涨到 5.5 ms、MNNVL all-reduce 等待从 ~10µs 涨到 3.6–4.7 ms。修复后 batch 97 为 1,523→3,876.85 tok/s（2.55×），与 batch 96 持平。修复不覆盖投机解码开启场景，未跑模型评测。

部署动作：升级前自查 max_num_seqs 是否为 8 的倍数；旧版本的即时缓解是对齐捕获阶梯。饱和压测复现的是生产事故形态，不是最优形态。

vLLM #56562

DSV4.1 元数据 Triton 融合

可测事实：解码元数据内核 191.10→46.27µs（4.13×）、launch 77→17；E2E 并发 1 TPOT −5.82%（DSpark 自适应验证 −18.20%）、并发 1 吞吐 +22.3%；但并发 1024 收益仅 1.4%。24 个用例与基线逐位一致。

边界：低并发/投机部署收益最大；高并发不要期待 E2E 变化。作者明示收益消失点，罕见。

vLLM #56853

ROCm HCA 双流重叠

可测事实：压缩器拆辅助流与 wqa/wkv 并行，MI355X 级 TP8：并发 1 TTFT −15.01%、吞吐 +3.43%；并发 4/16/64 增益降至 +2.68%/+1.56%/+0.96%。GSM8K 门禁通过。

边界：默认开启无需配置；又一条并发越高收益越小的曲线，高并发 ROCm 部署不据此预估。

SGLang #40105

fused finalize 默认翻转

可测事实：FlashInfer MoE fused finalize 默认 True→False，理由数值精度；代价表公开：W4A4 1-token 延迟 +21.75%、16k tokens +12.55%，W4A16 反而 −9.20%。精度测试标注 Not run。

边界：预防性翻转——用已知延迟损失对冲未知精度风险；精度预算充足可显式开回。

满载悬崖与"被回退的优化周"：kernel 收益在真实服务里被什么杀死。

vLLM #57355 · SGLang #40105/#40148 · vLLM #57680 · #57555 · llama.cpp #28761 · arXiv:2609.17863

本周至少六条独立证据指向同一个模式：内核层的正收益，在真实服务的并发位置、尾时延、精度预算或非调参硬件上被吃掉。vLLM 的满载悬崖只在饱和处触发——常规 CI 看不到，压测过载反而复现事故；SGLang 一周内两次把新内核优化回退为默认关闭（fused finalize 因精度、TopK v2 因 P90 交互性 +10.0% 差于默认）；vLLM 贡献者用 A30 扫描证明 H100 上调好的 KV offload 阈值在别的卡上是 2.4–3.8× 反优化；llama.cpp 的 tile 上限被双向基准证伪；arXiv 上的 Pareto Atlas 干脆把"FP8 KV cache 全错、n-gram 投机零收益"写成可复测的负结果网格。

深挖 03

国产推理的两个定价方向：降价通道与提价通道共享同一个前提。

DeepSeek 计费路由 · 智谱 FlashX · DeepJIT · CANN 口径

同一周，DeepSeek 把 Pro 流量强制迁到 Flash 价（峰值输入 −77%），智谱把 FlashX 提速 5 倍同时提价 2.5 倍并归因"10 万张国产芯片"。两条路线可以同时成立，但前提不同：降价通道要求单位 token 成本真实下降——它有可复核的支撑（计费规则公开；V4.1-Flash 权重 9/10 放出后，FlashMLA/DeepGEMM/DeepEP 一周四笔实质修复，新开源的 DeepJIT 把昇腾 NPU 设为一等后端）；提价通道要求买方为"国产规模化"支付溢价——而该规模主张本周在 HN 403 点讨论中零独立复现，仅有客户侧 API 慢与配额消耗快的体感反差。华为同场给出的 CANN 月活 5200 与"生态拐点"口径，恰好是两边都可以拿去复核的第三方锚点。

证伪：若 V4.1-Pro 上线后价格回归 Pro 档，降价叙事收窄为清库存；若 FlashX 提价后第三方网关份额数据下滑，提价叙事收窄为营销。在 CANN 社区数据或独立 serving 复测出现之前，"10 万张/3×"应保持在传闻档，不进入容量模型。
