SGLang v0.5.20 · 9/18

713 个 PR 的季度版：升级清单里最贵的是"消失的东西"。

内核层：SM120 的 DSV4-Flash 从 torch fallback 换 DeepGEMM paged-MQA sparse-MLA indexer + FP4 MoE（4×RTX PRO 6000 decode TPOT 36.1→10.5 ms、TTFT 8K→128K 降 20%）；TRT-LLM attention 内核覆盖 DSV4 CSA/HCA 层（B200 decode ~1.45× 于 FlashMLA）；FlashInfer MegaMoE 接入 NVFP4 prefill +11.9%。默认层：`/v1/responses` 不再驻留内存，未开 `--enable-response-store` 时检索、`previous_response_id`、后台请求一律 400，PD 部署禁止开启；prefill CP v1 删除；CUDA 12 轮子退役（v0.5.19 为最后一版）。收益层：统一 radix 树 SWA 分支点缓存把共享系统提示命中率从 43.8% 提到 60.8%、mean TTFT 1.57→1.07 s；ROCm 分阶段暂存拷贝让 4×MI355X 的 GLM-5.2 加载从 505.7 s 降到 40.4 s。

vLLM #57604

MegaMoE staging 门控

可测事实：8-token staging tile 在 2–16 token 内核回归（16 token：2.400→2.752 µs）、32 token 持平、64 token 起改善、8192 token 达 5.4×；NVFP4 gather 在 100K 行、1–8 请求时 −18% 至 −88%。最终按"≥64 token 才启用"门控；端到端合成 forward 下 Q16K+KV100K −3.51%。

边界：作者报告，非 serving 吞吐；低并发部署收益为 0，不要据此预估。

vLLM #57421

Humming workspace 共享

可测事实：scratch 对象 40→1，8192 token 时存储 −97.5%，B300 单卡初始化后省 9.836 GiB 驻留显存。但双基线互相只匹配 669/1319，改后 690/1319——改善低于基线自身噪声，作者明确"不排除因果精度影响，原因未解决"。

边界：显存收益照收，精度等价不闭环；量化敏感业务升级后自跑 GSM8K 对照。

SGLang #40313

SWA/Mamba radix 删除

可测事实：独立 SWA/Mamba radix cache 实现从主干移除，统一 radix 树（v0.5.20 分支点缓存）成为唯一路径；配套 #40354 修复 SWA prealloc 回收经 DSV4 HiSparse 分配器的通路。

边界：依赖旧独立缓存行为的部署无回退选项；SWA+共享前缀负载实测命中率迁移。
