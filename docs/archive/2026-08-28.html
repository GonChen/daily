Executive readout

可信的 fast path，不仅要快；还要说明它预留了什么、在哪些形状切换、遇到反例如何退回。

本期五条一手 PR 将“性能”拆为容量、地址和缓存路径。SGLang 的 DeepEPv2 以显式 token capacity、模型/量化 gate 换取可捕获 decode；MI355X 的 MTP attention 在 70k context 服务中有吞吐收益，但 C16 TPOT 仍回归。另两条改动把 2 GiB 地址溢出和 20 分钟冷 JIT 变为可行动的问题。TensorRT-LLM 则把混合 NVFP4 KV 的 route 写成硬约束。所有数字均为 PR 作者报告。

工程检查

性能开关的 API 应返回“为什么没有进入 fast path”。

最小复测清单

用四个字段阻止“标题数字”进入生产决策。

固定模型/权重、GPU/驱动、TP/DP/EP、输入输出与并发；报告实际 allocation、route/eligibility、cold/warm、P50/P90/error；保存前后 A/B 原始输出；将不支持组合和 CI 状态写为 release gate。没有这些字段的性能值只能是候选线索。
