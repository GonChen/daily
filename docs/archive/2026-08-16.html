01｜竞争单位从“单颗 GPU”扩大成“芯片 × 系统 × 资金”

AMD 融资是硬事实，TPU v10 合作只是传闻，但两条信号放在一起，指向同一个战略问题：AI 芯片公司要同时负担先进制程、HBM、互连、机架、电源、软件与客户定制。估值不应只看训练 benchmark，还要看能否锁定产能、垫付研发并进入超大客户的协同设计周期。

观察链：定制芯片设计份额 → 先进封装预订 → 机架交付 → 软件迁移成本 → 收入确认。任何一环没有官方证据，都不该提前算进确定收入。

02｜“虚拟新增 GPU”可能比新建机房更快

数据中心项目被社区、电力与许可延后，而 OpScale 给出最高两位数资源节省。两者共同说明，近期最可控的供给增量可能来自调度、批处理、算子与模型压缩，而不是等待新园区通电。

实践提示：先量化 token/SLO/GPU-hour，再讨论扩容；把利用率、尾延迟与能耗放在同一张成本表。

03｜Coding Agent 的护城河下沉到 harness

Claude Code 修资源与协议，pi 增强工具约束，Codex 保持快速预发布节奏；新论文又提醒 harness 会显著改变 agent 结果。下一阶段差异化会来自上下文整理、权限边界、工具 schema、会话恢复和可观测性。

采购提示：不要只测“能否一次写对”；要测失败恢复、长任务漂移、成本、凭据隔离和可审计性。
