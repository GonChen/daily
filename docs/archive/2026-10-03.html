论文、开源与社区复现

failure conditions as artifacts
评测方法论 · 作者报告

两篇论文同时攻击"怎么测"，而不是"怎么快"。

Periodic Weak Spots（arXiv:2609.36322）：分块 KV 压缩引入"相位"坐标，同信息跨相位检索精度可差 40 个百分点，平均分完全掩盖——长上下文评测必须按压缩相位扫描。KL vs 翻转率（arXiv:2610.00694）：802 个压缩副本实验证明 argmax 翻转率与总变差以 1.05 比例直接对应，KL 在 11% 配对中误判方向；vLLM 投机解码中 TV 预测 draft 接受率误差仅 1.1–2.4% 且免校准。压缩验收应改报 TV/翻转率。

2 篇方法论
量化与投机 · 带工件

循环状态与训练语料，各被标上一个失效条件。

STEPQuant（arXiv:2609.38169）：对 Delta-rule 循环状态直接低位宽量化会严重掉精度（误差随状态更新传播），时空 PTQ 让 4-bit 胜过均匀 INT8、SGLang 集成后服务内存最高降 68.7%。ALR-IRA（arXiv:2609.38795）：块投机解码训练语料中的单个 off-policy token 使其后槽位监督全部失效，重标注后 greedy 接受长度最高 +36.5%。理论侧：一致亚二次注意力近似被证明不存在——稀疏注意力的有效性必然依赖输入结构假设。

支持面收窄的代价清单：每次"聚焦"都把成本转嫁给部署方。

FlashMLA · TRT-LLM · 10/23 大限 · #59305 · #29774

本周至少六笔动作在收窄"什么还能用"：FlashMLA 砍 Hopper 与 V3 系并改 KV 格式（H100 用户钉旧 commit、升级重建缓存）；TRT-LLM 用 11 条 known-issue 收窄 PD 与低精度承诺（含跨请求内容错乱这条多租户红线）；OpenAI 10/23 把旧模型统一映射进 5.6 系；FlashMLA 的 pin bump 静默带回 8 GiB 瞬时分配（#59305）；llama.cpp 的 CPU FA 静默输出 -inf（#29774）。共同点：默认路径变了，而其中一半的错误是静默的——格式错会崩，守卫回滚、CPU 回退和数值溢出不会。

部署清单：①迁移窗口按"收窄日历"倒排（9/30、10/14、10/23）；②diff 审查包含"不再支持什么"；③跨请求隔离性测试升级为发布门禁（PD 串扰、DSpark KV 覆写、Ollama 泄漏三案同型）；④显存曲线随内核 pin 重测（公式已给全）。证伪：若 rc30 证明 PD 串扰为测试性问题、或 #59305 被证为特定 batch 形态特有，对应红线降级。

深挖 03

Agent 从会话制到常驻制：护栏的归属从产品层移到运维层。

Dots · Claude Code 2.1.288 · Codex 0.160 · Harness rc.2

四家厂商在同一周改写"运行时长"语义：OpenAI 的 Dots 把常驻 agent 带给全付费档；Claude Code 规定时限只管无人值守会话、交互会话无限时，同时把无人值守重试封顶 3 次；Codex 的 Guardian 可以回捞历史指令做审计；DeepSeek Harness 走到 0.2.0-rc.2 并强制 Messages API。共同推论：**会话制"一次任务一次计费、跑完即止"的心智失效**——常驻 agent 的成本是速率问题，预算、超时与重试上限必须外置到编排层（Claude Code 内建重试封顶正是承认了这点）；审计面随常驻与回捞同步扩大；Astra 的 3 天暂扣证明旗舰可用时间是安全变量，依赖最新旗舰的管线需要降级预案。证伪：若 Dots 公开文档出现非 Pro 档的时长/配额硬限制，"全付费档常驻"收窄；若 Harness GA 后恢复 Chat Completions 兼容层，迁移代价下调。
